— RELEASE WINDOWS —

发行窗口期：为什么“首播”不会同时在所有地方出现

电影版权按时间、地区、平台拆开卖，这是正版世界的常识。

院线窗口

先电影院。这时候任何“免费全集”都高度可疑。[7](@ref)

发行方公告

片方/平台发“X月X日上线 X 平台”，这才是可信首播信号。

订阅/会员

进爱优腾芒、海外 OTT；老用户免费，新片可能另收租片费。

广告免费

几个月后转广告型平台/免费区，合法但片单会缩水。

公共领域

版权到期进入公共领域，档案馆/正版平台都能放，最稳。
